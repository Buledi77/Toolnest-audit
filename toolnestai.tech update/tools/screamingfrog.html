Screaming Frog review: deep crawling without a subscription

Screaming Frog is a desktop crawler, not an SEO suite. It audits up to 300 technical issues, renders JavaScript, extracts custom data and exports everything for a developer. At £199 per year it is the best-value specialist tool in most SEO stacks, provided you already know what to target.

Screaming Frog overview

The SEO Spider crawls a site the way a search bot would, then reports what it finds: broken links, redirect chains, missing canonicals, duplicate metadata, blocked resources, orphan pages, hreflang errors and rendering problems. A paid licence removes the 500-URL cap and unlocks configuration, saving and advanced features.

Why it stands out

Nothing else at this price gives you the same control over a crawl. The free tier is genuinely usable for small sites, and the paid licence costs less per year than a few months of a typical SEO subscription.

Who Screaming Frog is best for, and who should skip it

Best for

  • Technical SEO audits where the crawl is the deliverable
  • Site migrations, including staging-versus-production crawl comparisons
  • Large sites where cloud crawl quotas are too restrictive
  • JavaScript-heavy sites that need rendered HTML inspected
  • Agencies that need clean CSV exports to hand to developers

Skip it if

  • You need keyword research, backlink data or rank tracking; the crawler has none
  • You want a cloud dashboard and scheduled reports without running a desktop app
  • Your site is small and the free 500-URL crawl already covers it
  • You are not comfortable interpreting technical crawl output

Screaming Frog pros and cons

Pros

  • Over 300 checks covering errors, redirects, metadata, canonicals, hreflang, security and accessibility
  • JavaScript rendering with stored rendered HTML, useful for React, Vue and Angular sites
  • Custom extraction with XPath, CSS and regex, plus custom JavaScript during a crawl
  • Integrations with Google Analytics, Search Console and PageSpeed Insights
  • Crawl comparison for migrations and progress tracking
  • CLI and MCP support for automation, plus a low annual price per machine

Cons

  • No keyword database, backlink index, rank tracking or content tools
  • Desktop installation and local resources; very large crawls need RAM and storage
  • Licence is per machine and renewed annually
  • Advanced configuration has a learning curve, and the interface is utilitarian
  • Log File Analyser is a separate product with its own licence
  • Not a collaboration platform; sharing means exporting files

Features that matter in practice

Crawling and auditing

Crawls like a search bot, discovers links, reports status codes, redirects and indexability.

Metadata analysis

Flags missing, duplicate, long or short titles, descriptions and headings across the crawl.

JavaScript rendering

Renders pages in headless Chromium and stores both source and rendered HTML.

Custom extraction

Pulls specific elements from HTML using XPath, CSS or regex, or runs custom JavaScript.

Integrations

Connects to GA, Search Console and PageSpeed Insights to enrich crawl rows with performance data.

Automation

Command-line interface, scheduling and an MCP server for repeatable audits.

Frequently asked questions

Is Screaming Frog free?

There is a free version that crawls up to 500 URLs per crawl with advanced features restricted. The full SEO Spider licence is £199 per year per machine and removes the URL cap.

Does Screaming Frog do keyword research?

No. It has no keyword database, backlink index or rank tracking. It is a crawler and technical audit tool, so you need separate research data.

Can Screaming Frog crawl JavaScript sites?

Yes. It can render pages in headless Chromium and store both the source and rendered HTML, which is essential for many modern frameworks.

Is Screaming Frog worth it for a small site?

If your site is under 500 URLs, the free version may be enough. Buy the licence when you need JavaScript rendering, custom extraction, saved crawls or larger audits.
